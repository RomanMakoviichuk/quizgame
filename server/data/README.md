# Словник тварин для «Гарячої бомби»

`ukrainianAnimals.json` — локальний словник для міні-гри «Гаряча бомба»
(676 назв: ссавці, птахи, риби, комахи, плазуни, земноводні, павукоподібні,
ракоподібні, молюски й інші). Гра читає його з диска при першому використанні
і нічого не завантажує з інтернету під час гри.

Формат запису:

```json
{ "word": "рись", "category": "ссавець", "accepted": true, "source": "curated+wiktionary" }
```

`source`:
- `curated` — перевірений вручну список (`sources/curated_animals.txt`);
- `wiktionary` — сторінка з англійського Вікісловника, категорія
  `Category:uk:Animals` і її підкатегорії (зібрано через MediaWiki API,
  кожне слово переглянуто вручну — `sources/review.txt`; відкинуто частини тіла,
  упряж, продукти, загальні слова на кшталт «птах», «риба», зменшувальні форми,
  русизми);
- `curated+wiktionary` — є в обох джерелах.

Словник не містить «усіх» назв тварин української мови — це практичний набір
для гри. Державний кадастр тваринного світу (data.gov.ua, `mepr_04`)
переглянуто, але для гри він не підходить: там переважно латинські наукові
назви, а кирилиця у файлі пошкоджена.

## Як додати слова

1. Допишіть їх у `ukrainianAnimals.custom.json` (той самий формат), напр.:
   `[{ "word": "квезаль", "category": "птах", "accepted": true }]`
2. Перезапустіть сервер.

`accepted: false` вимикає слово. Невідомі слова, які гравці вводили в грі,
сервер записує в `animal-suggestions.txt` — їх можна переглянути й додати
до `ukrainianAnimals.custom.json`, якщо це справжні назви тварин.

## Перебудова основного словника

```
python -I sources/build_animals.py sources/curated_animals.txt <raw.json Вікісловника> sources/review.txt ukrainianAnimals.json
```
