# 🎉 Хто є хто!

Простий додаток вікторини з підтримкою кількох гравців у реальному часі.

## Технологічний стек

- **Сервер:** Node.js, Express, Socket.io
- **Клієнт:** React (create-react-app), Socket.io-client
- **Дані:** база питань — JSON-файл `server/content/content.json`, керується через адмін-панель `/admin`

## Як запустити локально

### 1. Встановити залежності сервера

```bash
cd server
npm install
```

### 2. Запустити сервер

```bash
npm start
```

Сервер запуститься на **http://localhost:3001**

### 3. Встановити залежності клієнта

У **новому** терміналі:

```bash
cd client
npm install
```

### 4. Запустити клієнт

```bash
npm start
```

Клієнт відкриється на **http://localhost:3000**

### 5. Тестування (комп'ютер + телефон)

**Ведучий (комп'ютер):**
1. Відкрийте `http://localhost:3000`
2. Натисніть «Почати гру» — створиться кімната з 6-значним кодом
3. Покажіть код іншим — вони вводять його на телефоні
4. Коли гравці підключились — натисніть «Почати гру» (макс. 7 гравців)

**Гравці (телефон):**
1. Запустіть клієнт з доступом у мережі: `set HOST=0.0.0.0 && npm start` (Windows) або `HOST=0.0.0.0 npm start` (Linux/Mac)
2. Відкрийте `http://<IP-комп'ютера>:3000` у браузері на телефоні (телефон і ПК мають бути в одній мережі)
2. Натисніть «Приєднатися» → введіть код кімнати та ім'я
3. Відповідайте на питання (за правильну відповідь — 10 балів)

## Керування питаннями — адмін-панель

Відкрийте **http://localhost:3001/admin** (пароль — змінна середовища
`ADMIN_PASSWORD`, типово `admin`).

- **Дашборд** — кількість категорій і питань, розбивка по категоріях.
- **Категорії** — створення / редагування / вимкнення / видалення. Гра показує
  ведучому лише активні категорії.
- **Питання** — таблиця з пошуком, фільтром за категорією/статусом і
  пагінацією. Редактор: текст + 4 відповіді + вибір правильної + складність.
  Кнопки «Дублювати» та «Зберегти і додати ще» для швидкого набору.
- **Імпорт / Експорт** — CSV або JSON. Імпорт перевіряє всі рядки перед
  вставкою; за помилки не додається нічого.

Формат CSV:

```
category,question,answer1,answer2,answer3,answer4,correctAnswer,difficulty,active
Географія,"Яка столиця України?","Київ","Львів","Одеса","Харків","Київ","easy","true"
```

Під час гри ведучий обирає одну категорію; система випадково бере 9 унікальних
питань із неї та перемішує відповіді. Деталі — `ARCHITECTURE.md`.

## Функціонал

- Підключення гравців через унікальний id сесії
- Показ питань по черзі всім гравцям
- Прийом відповідей і підрахунок балів
- Оновлення таблиці лідерів після кожного питання
- Фінальні результати після останнього питання
- Адаптивний інтерфейс для мобільних пристроїв
