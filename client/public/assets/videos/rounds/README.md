# Відео після раунду

Гра сама бере випадкове відео з потрібної папки. Щоб додати нове, просто
покладіть файл у папку: перезапускати сервер чи перезбирати гру не потрібно.

| Папка | Коли грає |
|---|---|
| `after-round/` | після кожного раунду, перед показом результатів |
| `results/all-correct/` | після результатів, якщо **всі** відповіли правильно |
| `results/partial/` | після результатів, якщо правильно відповіли **не всі** |
| `results/all-wrong/` | після результатів, якщо **ніхто** не відповів правильно |

Порядок після раунду: `after-round` → на екрані з'являються ✓/✕ → відео з `results/...`.

Правила для файлів:
- формат `.mp4` (також підходять `.webm`, `.mov`, `.m4v`), бажано 1920×1080, зі звуком;
- назви на кшталт `after-round_7.mp4`, `all-correct_4.mp4`, `partial_5.mp4`, `all-wrong_2.mp4`
  (назва може бути будь-якою, але краще без пробілів);
- одне й те саме відео двічі поспіль не повториться, якщо в папці більше одного файлу;
- якщо папка `results/...` порожня, гра покаже старе відео результатів.
