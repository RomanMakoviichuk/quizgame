# «Не кліпай!» — the things under the cup

Drop pictures here: **png, webp, gif, jpg or svg**, ideally a transparent
background, roughly square, ~400–600 px. Each round picks one at random.

- The file name is what the host calls it: `огірок.png` → «Запам'ятай, де огірок!»,
  `гумова_качка.webp` → «гумова качка» (`_` / `-` become spaces, a trailing number
  is dropped, so `ключ 2.png` is still «ключ»).
- Use a masculine noun if you can: the phone says «… був під стаканчиком 2».
- New files work at once: no rebuild, no restart (the server reads this folder
  every game and serves it straight from here).
- An empty folder → the «Меморі» pictures are used instead.
