# «Не кліпай!» (shellShock) — optional sounds

Everything works without files here: the cup swishes, knocks and the sparkle are
synthesized, the round bell / answer ping / victory and fail sounds come from
`/assets/sounds`.

| file | when | note |
|---|---|---|
| `background.mp3` | soft bed under the whole minigame (TV) | looped, volume 0.22 |

The things under the cup: drop pictures into `items/` (see `items/README.md`);
while it is empty, the «Меморі» pictures are used.
