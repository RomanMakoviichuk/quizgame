# Звуки «До міліметра!»

Усі файли необов'язкові: поки їх немає, грають стандартні звуки гри (або тиша).
Тріск рулетки й «клац» фіксації на телефоні гра синтезує сама — файлів для них не треба.

| Файл | Коли звучить (на ТВ) | Поки немає |
|------|----------------------|------------|
| `background.mp3` | фон на правилах і результатах | тиша |
| `workshop.mp3` | зациклений фон майстерні, поки всі міряють | тиша |
| `start.mp3` | старт заміру | `sounds/bell.mp3` |
| `lock.mp3` | хтось зафіксував рулетку | `sounds/click.mp3` |
| `extend.mp3` | на результатах стрічки виїжджають | тиша |
| `zoom.mp3` | наближення до цілі («вжух»/«дзинь» лупи) | тиша |
| `perfect.mp3` | найкращий влучив до 1 мм | `sounds/win.mp3` |
| `fail.mp3` | найгірший промахнувся на 3+ см (сумний тромбон) | `sounds/lose/2.mp3` |
| `fanfare.mp3` | фінальна таблиця | `sounds/win.mp3` |

Файли можна замінювати будь-коли — достатньо оновити сторінку ТВ.
