# «Меморі: кольоровий хаос» — предмети

Картинки предметів для міні-гри «Меморі». Гра сама перефарбовує їх у синій,
червоний, зелений або жовтий під час показу — оригінальні файли не змінюються.

## Як додати новий предмет

1. Поклади картинку в цю папку: **PNG або WebP з прозорим фоном**, предмет
   по центру, бажано ≥ 500 px по довшій стороні.
2. Додай рядок у `server/data/memoryItems.json`:

   ```json
   { "id": "teapot", "name": "Чайник", "image": "teapot.png" }
   ```

   - `id` — латиницею, унікальний (стане ім'ям файлу `web/<id>.webp`);
   - `name` — назва українською (показується в результатах);
   - `image` — ім'я файлу в цій папці (пробіли можна);
   - необов'язково `"colors": ["red", "blue"]` — якщо предмет можна фарбувати
     лише в деякі кольори (за замовчуванням усі чотири).
3. Зроби легку копію для телефонів (рекомендовано):

   ```
   python server/tools/build_memory_items.py
   ```

   Без цього кроку гра теж працює — бере оригінал, просто він важчий.
4. Перезапусти сервер. Більше нічого міняти не треба: предмет одразу потрапляє
   у випадковий вибір.

## Що добре перефарбовується

Перефарбовуються насичені кольорові частини предмета, зберігаючи тіні й
фактуру. Білі, чорні, сірі та металеві частини (очі, контури, світловідбивні
смуги) лишаються як є. Тому найкраще підходять предмети з одним явним «своїм»
кольором тіла.

`background.mp3` — фонова музика гри (грає на головному екрані).
