# «Вгадай мелодію» — музика

```
name-that-tune/
  background.mp3   фон міні-гри (не для вгадування)
  songs/           пісні, які вгадують гравці
```

## Фон

`background.mp3` грає на телевізорі від правил до підсумків. Коли звучить
уривок пісні, фон плавно стихає, а після уривка плавно повертається.
Щоб замінити фон — поклади інший файл з тим самим ім'ям.

## Як додати пісню

Гра читає папку `songs/` щоразу, коли починається, тож нова пісня підхоплюється
без перезапуску і без змін у коді.

1. Поклади в `songs/` короткий уривок (10–15 с) у форматі **MP3** (також
   підходять OGG, WAV, M4A) з іменем **`Виконавець - Назва.mp3`**, наприклад
   `Okean Elzy - Obijmy.mp3`. Тире можна й «—».
2. Якщо ім'я файлу неточне (скорочене, з помилкою, з «Official» тощо), задай
   правильну назву в `server/data/tunes.json`:

   ```json
   "Eminem - please stand up.mp3": { "artist": "Eminem", "title": "The Real Slim Shady" }
   ```

   Ключ — точне ім'я файлу. Необов'язково: `"start": 3` — грати з 3-ї секунди;
   `"skip": true` — не використовувати файл.

Правильна відповідь береться тільки з цього каталогу на сервері. Телефони
ніколи не бачать імен файлів: телевізор грає уривок за випадковим адресом
`/tune/<токен>`, а папка `songs/` через сервер не віддається.

Для гри потрібно щонайменше **5 пісень** з **4 різними назвами**; інакше гра не
запускається (сервер пише причину в лог), і замість неї йде інша міні-гра.
