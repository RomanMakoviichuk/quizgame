# Звуки «Гарячої бомби»

| Файл | Коли звучить |
|------|--------------|
| `background.mp3` | тихий фон усієї міні-гри на ТВ (гучність 0.14 — значно тихіше за ефекти) |
| `timer.mp3` | поки горить ґніт: зациклюється, гучнішає і пришвидшується ближче до вибуху |
| `change player.mp3` | бомба летить до наступного гравця |
| `bomb boom.mp3` | вибух |

Необов'язкові (поки їх немає — грають стандартні звуки гри):
`word-ok.mp3` (слово прийнято), `word-bad.mp3` (слово не підходить),
`countdown.mp3` (відлік 3-2-1), `tick.mp3` (тікання, лише якщо немає `timer.mp3`).

Файли можна замінювати будь-коли — достатньо оновити сторінку ТВ.
