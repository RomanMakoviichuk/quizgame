# Звуки «Ідеальної секунди»

Усі файли необов'язкові: поки їх немає, грають стандартні звуки гри (або тиша).

| Файл | Коли звучить | Поки немає |
|------|--------------|------------|
| `background.mp3` | фон на правилах і результатах (під час раунду — ніколи, щоб не рахувати під біт) | тиша |
| `tension.mp3` | зациклений тривожний гул, поки таймер схований | тиша |
| `start.mp3` | старт відліку (0.00) | `sounds/bell.mp3` |
| `hide.mp3` | різкий клац / глітч у мить, коли таймер зникає | `sounds/knife-slice.mp3` |

Відлік 3-2-1 — `sounds/beep.mp3`, тік кожної видимої секунди — `sounds/click.mp3`,
результати — `sounds/result.mp3` і `sounds/win.mp3`.

Файли можна замінювати будь-коли — достатньо оновити сторінку ТВ.
