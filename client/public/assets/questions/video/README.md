# Відео оголошення раундів

```
questions/video/
  Round_1/1.mp4, 2.mp4, 3.mp4 …   «РАУНД 1»
  Round_2/1.mp4, 2.mp4 …          «РАУНД 2»
  …
  Round_9/…                       «РАУНД 9»
```

- У кожній грі для раунду грає **наступне відео по черзі**: 1-ша гра — `1.mp4`,
  2-га — `2.mp4`, …, після останнього знову `1.mp4`. Черга пам'ятається між
  іграми і перезапусками сервера (`server/data/round-announce.json`).
- Імена файлів довільні, порядок — природний (`2.mp4` раніше за `10.mp4`).
  Формати: MP4, WEBM, MOV, M4V.
- Нове відео підхоплюється одразу, без перезбирання і перезапуску.
- Немає папки або вона порожня — замість відео на екрані напис «РАУНД N».
- Раунд 1: після оголошення одразу йде відео питання.

# Відео під питанням

```
questions/video/questions/*.mp4
```

Фон, що грає під питанням і таймером відповіді. Для кожного раунду береться
**випадкове** відео з цієї папки; у межах однієї гри відео не повторюються,
доки не прозвучать усі. Нові файли підхоплюються одразу. Порожня папка —
грає загальний фон `videos/main.mp4`.

# Порядок сцен одного раунду (телевізор)

```
Round_N/<по черзі>.mp4      оголошення раунду
   ↓ затемнення
questions/<випадкове>.mp4   фон під питанням і таймером
   ↓
videos/rounds/after-round/  ролик після раунду
   ↓ затемнення, 2,6 с — ✓/✕ біля гравців
videos/rounds/results/all-correct | partial | all-wrong
   ↓ затемнення
міні-гра або наступний раунд
```

Кожен ролик з'являється з темряви (~0,7 с) разом зі звуком, за ~0,9 с до кінця
плавно гасне, потім ~0,35 с темряви — і наступна сцена. Ролики в межах гри не
повторюються, доки не прозвучать усі з папки; оголошення раундів ідуть по черзі
між іграми. Битий або відсутній файл гру не зупиняє — сцена просто
пропускається.
