# Файли гри — де що лежить

Кожна папка відповідає частині гри. Назви латиницею, малими літерами, без
пробілів. Ролики в папках пронумеровані: `1.mp4`, `2.mp4`, …

```
assets/
  ui/                  дрібниці інтерфейсу: логотип, стрілка «назад», значок звуку, фон телефона
  characters/
    alive/1-8.png      персонажі гравців (номер = персонаж, якого обрав гравець)
    dead/1-8.png       ті самі персонажі — привиди
  sounds/              спільні звуки: beep, bell, click, notification, result, win, …
    kill/1-4.mp3       удар, коли персонаж гине
    death/1-4.mp3      крик після удару
    lose/1-4.mp3       програш у міні-грі (грає випадковий)

  menu/                головне меню і лобі
    background.mp4     відео-фон меню й лобі
    music.mp3          музика меню (і привітання гравців)
    lobby.webp         картинка лобі
  intro/               заставка перед грою
    intro.mp4          початок
    music.mp3          музика заставки
    players/1-8.mp4    поява персонажа N
    scenes/N.mp4       сцена персонажа N після появи (якої немає — пропускається)
    end.mp4            кінець заставки
  rules/rules.mp4      відео з правилами
  game/background.mp4  загальний фон гри (під таблицею балів тощо)

  rounds/              усе для раундів-питань (нові ролики підхоплюються без перезапуску)
    announce/round-1/ … round-9/   «РАУНД N»: у кожній грі — наступний ролик по черзі
    question/                      фон під питанням і таймером: випадковий
    after-round/                   після кожного раунду, перед результатами
    results/all-correct/           усі відповіли правильно
    results/partial/               правильно відповіли не всі
    results/all-wrong/             ніхто не відповів правильно
    results/fallback/              запасні, лише коли папка результатів порожня

  minigames/           міні-ігри, кожна в своїй папці
    hot-bomb/          «Гаряча бомба»
    math-rush/         «Тупоматика»
    memory/            «Меморі» (картинки предметів, web/ — легкі копії; див. README)
    name-that-tune/    «Вгадай мелодію» (songs/ — пісні; див. README)
    rat/               «Хто підмутив зарядку»
    rps/               «Камінь, ножиці, папір»
    true-false/        «Правда/Брехня»: game.mp4 — сама гра, aftermath.mp4 — після неї
    tug-of-war/        «Перетягування канату» (happy.mp3 — перемога в раунді)

  final/               фінальна битва
    background.webp    зала
    music.mp3          музика фіналу
    end-music.mp3      музика фінальних титрів
    monster.mp4        монстр у тіні
```

## Як додати ролик

- **Раунди** (`rounds/…`): просто поклади файл у потрібну папку — сервер
  підхопить його в наступному раунді, нічого перезбирати не треба.
- **Решта** (меню, інтро, міні-ігри, фінал): заміни файл, залишивши ту саму
  назву, і перезбери клієнт (`cd client && npm run build`).

Відео: MP4 (H.264), 1920×1080. Перед додаванням бажано стиснути — гра вантажить
їх по мережі на телевізор.

## Чого тут немає

- Великі вихідні картинки (PNG, з яких зроблено `web/*.webp`) — у `design/` в
  корені проєкту: вони не потрібні грі й не потрапляють у збірку.
- Файли, які гра не використовує, — у `design/unused/`.
- Старі колоди питань (`round1.json` …) — у `server/data/legacy-questions/`;
  питання тепер у базі, яку редагує адмінка.
